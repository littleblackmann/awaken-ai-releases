Awaken AI · 隱私與使用說明
公開測試版 0.3.0｜2026-10-17

這是一個在你的 Windows 電腦上執行的個人 AI 助理。安裝本身不需要 API Key，也不登入任何帳號。

你的資料
稱呼、偏好、提醒、對話記憶與設定保存在所選安裝資料夾內。OpenRouter Key 由你自行提供，使用 Windows 的使用者帳號保護機制儲存；安裝包不包含開發者的 Key、帳號或對話。

雲端 AI
開始對話、語音轉文字、合成聲音、搜尋或天氣查詢時，相關文字／音訊會依選用功能傳送至 OpenRouter 及其模型供應商。服務有各自的資料保留、處理與收費政策；這不是完全離線的服務，也不保證供應商不保留資料。使用費由你的帳號支付。
OpenRouter 隱私政策：https://openrouter.ai/privacy/
OpenRouter 資料政策：https://openrouter.ai/docs/guides/privacy/data-collection

麥克風與本機模型
瀏覽器會另外要求麥克風權限。開始對話／喚醒待命時才依你的操作使用收音。喚醒辨識與聲紋有本機運算；第一次使用可能從 Hugging Face 下載公開模型，耗時取決於網路。你可以結束對話停止待命。

音樂
音樂是選用功能。Pear Desktop 與 YouTube Music 是獨立服務；登入由你在播放器內完成，帳號保存在這台電腦。安裝助理不代表已購買音樂會員，也不會自動替你登入。

更新與移除
檢查更新會連到 GitHub。程式更新會驗證發布簽章與檔案雜湊。更新來源為獨立的公開 GitHub 發行區，不需要 GitHub 帳號。
覆蓋安裝／一般解除安裝保留執行後產生的個人資料。若要清除 Key、記憶、音樂登入與全部設定，先在助理「系統與重設」執行完整原廠重設，再解除安裝。

權限與測試版
安裝只針對目前 Windows 使用者；不修改 PATH、不裝全域 Python、不加入開機啟動。安裝資料夾必須可寫入。選用的平板 HTTPS／憑證設定需另外由你操作。
此為公開測試版，不是緊急通知或專業判斷服務；AI 回答及提醒功能仍需由你確認。請從官方發行區下載測試；第三方元件各依隨附授權使用。
